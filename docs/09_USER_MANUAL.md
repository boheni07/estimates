# [산출물-09] 시스템 사용자 매뉴얼 (System User Manual)

---

## 1. 시스템 접속 및 로그인

1. 웹 브라우저를 열고 `http://localhost:3300` 또는 `http://localhost:3300/login`에 접속합니다.
2. 발급받은 **아이디(ID)**와 **비밀번호(PW)**를 입력하고 [로그인] 버튼을 클릭합니다.
   * **초기 관리자 계정**: `admin` / `password`
   * **샘플 직원 계정**: `hong` / `password` (홍길동 팀장)
   * **샘플 엔지니어 계정**: `kim` / `password` (김수석 엔지니어)
3. 상단 헤더 우측에서 로그인된 사용자의 성명, 직위, 소속부서, 관리자(`ADMIN`) 배지를 확인할 수 있습니다.

---

## 2. 좌측 메뉴 접기/펼치기 (Collapsible Sidebar)

* 사이드바 상단 우측의 **접기 버튼(`PanelLeftClose`)**을 누르면 메뉴가 아이콘 형태(`w-20`)로 축소되어 메인 작업 영역이 넓어집니다.
* 접힌 상태에서도 각 아이콘에 마우스를 올리면 **플로팅 툴팁**으로 메뉴명이 안내됩니다.
* 브라우저에 접힘 상태가 저장되므로 다음 접속 시에도 동일한 상태가 유지됩니다.

---

## 3. 고객사(거래처) 및 프로젝트 전담 연락망 등록

1. 좌측 메뉴에서 **[고객사(거래처)]** $\rightarrow$ `[+ 고객사 신규 등록]`을 클릭하여 상호명, 사업자번호, 대표자, 주소를 등록합니다.
2. 좌측 메뉴에서 **[프로젝트 관리]** $\rightarrow$ `[+ 신규 프로젝트 등록]`을 클릭합니다.
3. 소속 고객사를 선택하고, 프로젝트명과 함께 **고객사의 전담 담당부서, 담당자명, 직급, 연락처, 이메일**을 입력하여 저장합니다.

---

## 4. 새 견적서 작성 및 실시간 요율 계산

1. 좌측 메뉴의 **[새 견적서 작성]**을 클릭합니다.
2. 대상 고객사 및 프로젝트를 지정하고 견적서 제목을 입력한 후 `[견적서 생성 및 작성 시작]`을 누릅니다.
3. **SW 개발비 (직접인건비) 입력**:
   * `[+ 인력 추가]`를 눌러 담당 직무를 입력합니다.
   * `기술 등급` 콤보박스에서 `총괄관리자(PM)`, `특급`, `고급`, `중급`, `초급`을 선택하면 **2026 KOSA 표준 노임단가가 자동 반영**됩니다.
   * `공수(M/M)`를 입력하면 직접인건비가 즉시 계산됩니다.
4. **물품 및 솔루션 / 라이선스 입력 (2줄 카드형)**:
   * 1줄: 품목 구분, 품목명, 규격/사양을 넓은 입력창에 넉넉하게 기재합니다.
   * 2줄: 단위(EA), 수량, 단가(원), 할인율(%)을 입력하면 우측에 공급금액이 자동 산출됩니다.
5. **직접경비 (실비)**: 여비교통비, 인쇄비, 장비임차료 등 실비 항목을 추가합니다.
6. **우측 슬림 플로팅 요율 패널 활용**:
   * 화면을 아래로 스크롤해도 우측 요율 패널이 상단에 고정되어 항상 따라옵니다.
   * 제경비율(110%), 기술료율(20%), 이윤율(25%), 특별할인액(원), 부가세율(10%)을 1줄씩 편리하게 조정할 수 있습니다.
7. 우측 상단의 `[견적서 저장]` 버튼을 클릭하여 저장합니다.

---

## 5. 견적서 버전 관리 및 타인 수정 시 자동 분기

* **작성자 본인이 수정할 때**: 견적서 내용이 정상 덮어쓰기 저장됩니다.
* **다른 직원이 타인의 견적서를 수정할 때**:
  - 화면 상단에 *"타 사용자 견적서 편집 안내 (저장 시 v1.1 마이너 버전으로 자동 분기)"* 경고 배너가 표시됩니다.
  - 저장 시 **기존 견적서는 보존되고 자동으로 v1.1 신규 견적서가 분기 생성**되어 수정자가 새 작성자로 등록됩니다.
* **버전 복제 버튼 (`GitBranch`)**:
  - 견적서 목록에서 보라색 브랜치 아이콘을 눌러 고객사 네고 사유를 입력하고 **v2.0(Major)** 또는 **v1.1(Minor)** 버전을 수동 복제할 수도 있습니다.

---

## 6. 공식 A4 인쇄 / PDF 출력 및 엑셀 다운로드

* **공식 A4 인쇄 / PDF**:
  - 견적서 목록에서 **프린터 아이콘(`Printer`)**을 클릭하면 공인 표준 견적 총괄표, SW인건비 산출서, 공급자 인감, 법적 근거가 포함된 표준 A4 인쇄 뷰가 열립니다.
  - `[공식 견적서 인쇄 / PDF 저장]` 버튼을 누르면 인쇄 미리보기 창이 호출됩니다.
* **4개 시트 다중 엑셀 내보내기**:
  - 견적서 목록에서 **다운로드 아이콘(`Download`)**을 클릭하면 ExcelJS 기반의 4개 시트(견적총괄표, SW인건비, 물품내역, 직접경비)가 포함된 `.xlsx` 파일이 즉시 다운로드됩니다.

## 7. 시스템 관리자 전용 기능 (ADMIN)

### 7.1 직원(사용자) 관리 (`/users`)
* 좌측 사이드바 하단의 **[👥 직원(사용자) 관리]**로 이동합니다.
* `[+ 신규 직원 등록]`을 통해 성명, 부서, 직위, 로그인 ID, 초기 비밀번호, 연락처, 이메일, 권한(`ADMIN`/`USER`)을 등록합니다.
* 기존 직원의 정보 수정 및 비밀번호 변경, 계정 삭제가 가능합니다.

### 7.2 열람 감사 로그 모니터링 (`/audit-logs`)
* 좌측 사이드바 하단의 **[🛡️ 열람 감사 로그]**로 이동합니다.
* 전사 직원들의 견적서 **화면 열람(`VIEW`)**, **공식 인쇄(`PRINT`)**, **엑셀 다운로드(`EXCEL`)**, **타인 수정 시도(`EDIT_ATTEMPT`)** 이력을 실시간으로 모니터링하고 액션별로 필터링할 수 있습니다.
